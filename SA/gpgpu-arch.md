## GPGPU 架构

GPGPU + DLA 是未来智驾芯片发展的主流道路，这里分析 GPGPU 的架构，后续结合算法分析未来发展趋势。

### GPGPU 的运算单元架构

CUDA 核心主要面对通用运算，如定点数的基本运算和浮点数的基本运算；特殊功能单元面向超越函数计算；张量核心面向矩阵运算，以应对大量的神经网络计算需求。

#### 运算单元的组织和峰值算力

算力指计算能力。一般来讲，不同的计算平台对算力有不同的衡量方法。GPGPU 注重通用计算场景中单精度浮点运算的能力，所以会采用每秒完成的单精度浮点操作个数，即 FLOPS 来衡量。峰值算力指理想情况下所有运算单元都工作时所能够提供的计算能力，它往往是硬件能力的一种衡量，并不能代表软件运行时的实际性能。对于单精度浮点操作而言，**每个 CUDA 核心每周期可以支持一个单独的加法或乘法操作**，还支持浮点融合乘加指令（FFMA）同时完成乘加两个操作，所以一般 GPGPU 的峰值算力是**按照 CUDA 核心满载执行 FFMA 指令的 2 个操作来计算的**。其他类型数据的算力也可以类似计算，所以我们能看到智驾芯片提供的各种精度下的算力，要注意区分。

以 Ampere 架构为例，单精度浮点 FP32 单元可以在一个周期完成一次全通量的 FFMA 运算，**相当于乘法和加法两个操作**。由上表可知，A100 配备有 6912 个 FP32 单元，每个单元的工作频率为 1410MHz。所以，A100 的 FP32 峰值算力为 2OPs×6912×1410MHz = 19.5TFLOPS。

对于双精度浮点 FP64 单元的峰值性能，同样可以使用上述计算公式，A100 包含 3456 个 FP64 单元，故 FP64 的峰值算力为 2OPｓ×3456×1410MHz = 9.7TFLOPS。

32 位整型运算单元与 FP32 单元数量相等，核心工作频率相等，可以用整型 FMA 指令来评估 A100 的 32 位整型峰值算力为 2OPｓ×6912×1410MHz = 19.5TFLOPS。

值得注意的是，还可以用 FP32 和 FP64 单元支持 FP16 数据运算。一般认为一个 FP32 核心可以支持 2 个 FP16 数据的运算，因此 Pascal、Volta 和 Turing 架构中非张量核心实现的 FP16 峰值算力为 FP32 峰值算力的 2 倍。在 A100 架构中，除 FP32 单元外，FP64 单元也可能被设计成支持 4 个 FP16 数据的运算，因此 A100 中非张量核心实现的 FP16 峰值算力表示为两部分峰值算力之和，为 78TFLOPS。

特殊功能单元的计算吞吐率取决于函数的类型，所以很难用峰值算力来衡量。表 5-5 中仅给出了其在可编程多处理器中的数量。

另外，NVIDIA GPGPU 的架构耦合了通用计算和图形处理的功能，但不同的产品有所侧重。自 Fermi 架构以来，每一代计算卡和图形卡都包含了 FP32 单元，并且将 FP32 单元和 INT32 的 ALU 整合在一个 CUDA 核心中。从 Volta 架构起，计算卡的 FP32 和 INT32 单元分离，而图形卡依然绑定在一起。但图形卡中的 FP64 单元往往都会大幅缩水，这也是两者面向不同的领域而导致的不同设计。

### GPGPU 张量核心架构

近年来，人工神经网络尤其是深度神经网络（DNN）发展迅猛，带动了深度学习应用对算力的巨大需求。GPGPU 作为具有高度可编程能力的通用计算加速设备，其计算能力随着神经网络的发展快速提升。为满足深度学习的算力需求，NVIDIA 公司在最近几代 GPGPU 中添加了专门为深度神经网络设计的张量核心，大幅提升了 GPGPU 的矩阵运算算力。

本章以 NVIDIA GPGPU 中的张量核心为例，结合典型神经网络的计算特征，介绍张量核心的架构设计特点，进而理解现代 GPGPU 对深度神经网络运算的加速方式。

#### 深度神经网络的计算

以卷积神经网络为代表的深度神经网络呈现出巨大的算力需求，对硬件平台和计算架构提出了极高要求。随着深度学习的普及，神经网络加速器涵盖了 GPGPU、ASIC、FPGA、DSP 及存算一体器件等多种架构类型。其中，GPGPU 凭借强大的算力、良好的可编程性和完善的神经网络加速库，成为目前加速深度学习训练和推理过程的首选架构。

##### 深度神经网络的计算特征

以经典的 AlexNet 卷积神经网络为例，介绍深度神经网络计算的基本特征及带来的硬件设计挑战。AlexNet 由 Hinton 团队在 2012 年提出，用于对整张图像按内容主体分类。该网络接受 227×227×3 的图像输入，经各层变换得到 1000 维向量，向量中每一维代表一种图像类别的预测概率，取概率最大项作为图像类别。

AlexNet 网络层类型主要有：

- 以卷积层为代表的线性计算层，主要由乘加计算构成。
- 以 ReLU、Sigmoid 函数为代表的非线性计算层，由指数、三角函数或分段线性计算构成。
- 以最大池化为代表的下采样层，由逻辑或线性运算构成。

其中，卷积计算层占据 AlexNet 网络的主要部分和运行时间，其他神经网络中卷积计算时间占比也很高，因此对卷积计算的加速是神经网络加速的关键。

深度神经网络的卷积计算具有多通道、多规格特点，一般有输入特征图 [N, C_in, H_in, W_in] 和卷积核 [C_out, C_in, K, K]，输出特征图 [N, C_out, H_out, W_out]，其中 H_out 与 W_out 由 H_in、W_in 与步长 S 决定。卷积层的算力需求可表示为 C_in×2×K×K×H_out×W_out×C_out。通过计算 AlexNet 各卷积层的计算量发现，**线性计算层在网络算力需求中占主导，而卷积计算又在线性层中占主导**。

从参数量与运算量对比及卷积计算伪代码可知，卷积神经网络中数据具有很高的重用性，这对缓解带宽压力很重要。

虽然 AlexNet 的算力需求在 2012 年可被当时的 GPGPU 接受，但随着神经网络的发展，其层数和参数量不断提升，训练计算量呈指数级增长，远超摩尔定律速度，导致算法和硬件平台的算力差距逐年增大。

近年来，**深度神经网络模型的卷积类型趋于多样化**，如转置卷积、depthwise 卷积、deformable 卷积、dilation 卷积等，这使得以 ASIC 为基础的神经网络加速器设计面临挑战，因其大多注重卷积性能和能效比，**在可编程性上妥协，只能针对特定神经网络加速，难以支持日益多样化的深度神经网络**。

在深度神经网络加速器设计中，**精度是重要考量因素**，加速器分为训练和推理用途，训练多用单精度浮点数（FP32），推理多用半精度浮点数（FP16）或更低精度的整型数（如 INT8、INT4 等），因为神经网络能容忍一定精度误差，通过重训练等操作可恢复精度损失，同时提升硬件性能。

综上所述，深度神经网络的计算特征主要包括：

- 计算量大且集中在卷积操作；

- 卷积参数量大，带宽需求高；

- 卷积参数存在高度复用可能；

- 网络算法、结构不断变化，可编程性要求高；

- 网络本身具有精度容忍性，推理需要多种可变换精度支持；

GPGPU 在各方面都能为深度神经网络提供不错的解决方案，其大量硬件运算单元和高吞吐高带宽存储设计能提供强大计算能力，针对矩阵运算和卷积在软件层面有灵活完善的加速库支持，近年来增加的张量和矩阵核心硬件大幅加速矩阵运算，还支持多种精度，且本身的可编程性能够适应多种操作。

本章将重点关注 GPGPU 加速神经网络计算的方式，前半部分关注卷积计算方法，即如何将卷积运算转化为矩阵乘法运算，后半部分关注 NVIDIA GPGPU 的张量核心结构及其工作流程。

##### 卷积运算方式

卷积神经网络的主要计算集中在卷积层，加速神经网络的关键在于加速卷积层，以下介绍几种卷积运算方式。

**基于通用矩阵乘法的卷积**

在 GPGPU 上进行卷积计算最常用的方式是**将卷积运算转化为通用矩阵乘法（GEMM）操作**，利用 GPGPU 软硬件对通用矩阵乘法的优化来加速卷积计算。

以 5×5 输入特征图与 3×3 卷积核的卷积为例，卷积核以窗口滑动方式进行计算，每个窗口内的运算类似矩阵运算中的一行乘一列，因此可将特征图窗口展开为左矩阵一行，卷积核展开为右矩阵一列，偏置值拓展为向量，从而将卷积转化为矩阵乘法运算。

当考虑输入通道参数 C_in、输出通道参数 C_out 和输入特征图数量 N 时，可通过相应的转化方法将整个卷积层的运算转化为矩阵乘法运算，这种方法称为 im2col 操作。但该方法会增大输入特征值的存储空间，因为特征图数据出现大量重复，针对此问题，NVIDIA 的神经网络计算库 cuDNN 中提到了一些优化方式。

**软件直接卷积**

软件直接卷积的方式将卷积伪代码中的 7 层循环映射到 GPGPU 的计算单元上，不同的卷积核映射至不同的线程块，每个线程块内存储该卷积核下所有通道的权值，处理若干输入特征图，输出相应的输出特征图，最终汇集成结果。该方法优点是不需要额外辅助存储空间，能灵活适应各种卷积，缺点是性能和功耗难优化，且卷积参数改变时需重新优化，开发优化的卷积加速库困难。

**基于快速傅里叶变换**

快速傅里叶变换（FFT）将时域的卷积操作转化为频域的乘法操作，一定条件下可降低卷积计算复杂度。对单通道输入特征图和卷积核，利用 FFT 实现 2D 卷积的过程包括扩充卷积核、进行 FFT、逐元素乘、逆傅里叶变换。基于 FFT 的卷积以频域乘法替代原卷积操作，降低了计算复杂度，但在实际应用中存在局限性，如频域乘法为复数运算、卷积核扩展会消耗额外空间、对步长不为 1 的卷积效率下降等，因此只在一些规格的卷积上有效。

**基于 Winograd 变换**

由于卷积核在特征图上滑动时窗口内特征图元素有规律性重复，Winograd 算法利用此重复特性，对特征图和卷积核进行映射变换，用更少乘法完成卷积运算，实现加速。以 3×3 卷积核与 4×4 特征图的 Winograd 卷积为例，通过线性变换、矩阵乘法和反变换得到输出特征图。Winograd 能够加速卷积的原因在于线性映射可通过加法和移位运算完成，且映射后的矩阵乘法减少了乘法次数，但加法操作增加，还需要额外变换计算和存储变换矩阵，一般适用于较小卷积核，且不适用于步长不为 1 的卷积。目前，NVIDIA 的 cuDNN 库中提供了面向 3×3 和 5×5 卷积核的 Winograd 变换加速方法。

#### 张量核心架构

通用矩阵乘法可在 GPGPU 的 SIMT 单元上执行，具有很高通用性，但 SIMT 通路需兼顾通用运算和科学计算，**配备高精度运算单元，峰值算力受硬件面积和功耗限制，难以满足深度神经网络计算需求**。2017 年 5 月，NVIDIA 发布 Volta 架构的 GPGPU V100，引入专门为神经网络计算设计的张量核心单元，意味着 GPGPU 在通用计算基础上加入领域专用特性，通过增加专门硬件支持，联合原有 SIMT 单元满足特定领域计算需求。

##### 张量核心架构特征概述

**神经网络具有大算力需求、低精度容忍度等特点**，张量核心的高度并行乘累加结构可利用低精度运算器（16/8 比特及其他）提升算力，保证合理功耗开销。神经网络所需的大规模矩阵乘法运算具备良好的计算 / 访存比，矩阵规模越大，计算 / 访存比越高，加上卷积网络自身的数据复用特性，可通过合理分块降低存储带宽压力。

矩阵乘法的计算模式相对固定，在张量核心之前，面向神经网络的专用加速器多遵循向量乘法单元和加法树单元结构或乘加单元组成的脉动阵列结构两种计算模式，差别在于数据流调度方式。张量核心则遵循矩阵乘法计算模式，结合寄存器读取共享，优化数据复用减少功耗。

##### Volta 架构中的张量核心

张量核心在 NVIDIA 的 Volta 架构中首次被提出，每个 SM 内含 2×4 个张量核心，8 个张量核心与 CUDA 核心在逻辑上等同，分布在 4 个处理子块中，每个处理子块含两个张量核心。每个张量核心可在一个周期内完成 4×4×4=64 次乘加运算，两个输入矩阵为 FP16 格式，累加矩阵与结果矩阵为 FP16 或 FP32 格式。V100 包含 80 个 SM，640 个张量核心，在 1.53GHz 工作频率下，**算力达 125TFlops（FP16）**。

Volta 架构为张量核心矩阵乘法操作提供新的 wmma 指令，可完成 16×16×16 的矩阵乘加运算，由 4×4×4 的矩阵乘加拼接组合而成，其他矩阵形状需编程人员填充或拆分，且只支持 FP16 数据类型，Volta 之后的架构支持更广泛。

以下从矩阵乘法的编程抽象、矩阵数据的加载、计算过程和可能的硬件结构四方面介绍 V100 中张量核心的矩阵乘法计算流程。

**矩阵乘法的编程抽象**

在传统 SIMT 计算模型中，编程人员编写每个线程代码，线程独立完成计算。而在张量核心中，硬件为提高计算效率定制化设计，SIMT 模型改变，16×16×16 的矩阵乘法由特定 API 以线程束为粒度完成，编程人员不可见线程束内 32 个线程的具体执行过程。Volta 架构中调用张量核心编程的 API 包括 wmma::fragment、wmma::fill_fragment ()、wmma::load_matrix_sync ()、wmma::mma_sync ()、wmma::store_matrix_sync ()，这些 API 要求线程束内线程执行时参数一致，数据类型变为 fragment，执行粒度改变，这是张量核心带来的编程模型改变。

**矩阵数据的加载**

针对 wmma::load_matrix_sync () API，矩阵乘法的输入矩阵加载时，线程束内每个线程负责加载特定部分，形成数据与线程的映射关系。通过人为指定矩阵元素数值并加载至 fragment，打印线程可见内容，可理清映射关系。3 种 fragment 类型（matrix_a、matrix_b、accumulator）有不同的线程对应规则，矩阵加载过程相较于 SIMT 模型更复杂，但线程与矩阵元素关系由 API 隐式管理，是 SIMT 架构支持张量核心的折中。

**矩阵乘法的计算过程**

wmma::mma_sync () 的执行过程中，16×16×16 的矩阵乘加运算被拆分到每个张量核心，以 4×4×4 的小矩阵乘加运算分块执行，再协作完成。该指令被翻译成 PTX 的 wmma.mma 指令，进一步转换为 16 条 SASS 级别的 HMMA 指令，分成 4 组，每组 4 个步骤。一个 threadgroup 负责 4×8 大小的子块，32 线程分为 8 个 threadgroup，组合完成结果矩阵计算。计算时需要 threadgroup 之间共享并交换数据，因此寄存器需增加跨线程访问的硬件和机制。

**可能的硬件结构**

根据计算过程分析，推测张量核心硬件结构。一个 SM 包含 4 个处理子块，每个 block 含 2 个张量核心，一个线程束的 16×16×16 矩阵乘加运算由 2 个张量核心完成，每个张量核心可能拆分成 2 个独立结构支持线程方阵计算。每个 threadgroup 按 4 个 Set、每个 Set 分 4 个 Step 的方式，利用 8 个 threadgroup 并行处理，每个 Step 完成 2×4×4 矩阵乘加。张量核心内部可能包含 FEDP 单元、缓冲区等，通过缓冲区复用数据，减少对寄存器文件的访问，多个缓冲区经由操作数总线与寄存器文件相连，不同线程从操作数总线获取数据，并行完成计算。

##### 张量核心的发展

Volta 架构之后，NVIDIA 的 Turing 和 Ampere 架构也包含张量核心并不断改进，尤其是 Ampere 架构对张量核心进行了重要设计升级。

**Turing 与 Ampere 架构中张量核心概述**

Turing 架构于 2018 年发布，面向图形领域，在 AI 加速领域改变相对保守，张量核心较 Volta 架构变化不大，单位时钟周期性能甚至下降，全局存储器容量和带宽受限，制约了在深度学习方面的表现，但增加了矩阵乘加的尺寸和矩阵元素的数据类型，底层 SASS 指令也有调整。

2020 年发布的 Ampere 架构 A100 中，NVIDIA 大幅改进张量核心设计，**新增更多深度学习数据类型**，对稀疏化权重参数在硬件层面提供支持，当权重参数具有结构化稀疏特性时，张量核心峰值吞吐量可翻倍，每个张量核心性能相当于 V100 中的 4 个。

**张量数据类型与矩阵尺寸的变化**

深度神经网络具有低精度运算能力和精度容忍能力，GPGPU 借助张量核心支持多种运算精度，提升深度学习计算任务算力。从 Turing 架构开始，张量核心支持的矩阵乘法数据类型广泛增加，包括 INT8、UINT8、INT4、UINT4、binary 等，Ampere 架构进一步增加 BF16 和 TF32 类型。后两代架构的张量核心较 Volta 架构大幅拓展数据类型，覆盖主流数据类型，单条指令支持的矩阵乘加尺寸也不断增大，意味着硬件运算能力增强，数据复用增加，降低片上存储带宽需求。

**Ampere 架构张量核心工作模式的升级**

Ampere 架构中的张量核心性能提升明显，每个 SM 内 4 个张量核心算力相当于 V100 的 16 个，以下三点起到积极作用：

- 线程协作模式改变：Volta 和 Turing 架构中线程束内 8 个线程共享数据，Ampere 架构改为 32 个线程共享数据，相应指令修改，减少寄存器读写次数，相同寄存器带宽下可容纳更多张量核心运算。
- 优化的共享存储器：Ampere 架构加入异步复制指令，数据可直接从全局存储器加载到 SM 内共享存储器，节省 SM 内部带宽，避免为共享存储器数据分配寄存器，提升数据访问能力。
- 结构化稀疏：A100 张量核心加入结构化稀疏特性，支持权重矩阵中 2:4 的稀疏，通过软硬件协同，计算吞吐量增加 2 倍，存储与带宽需求降低 50%。

##### 扩展讨论：张量核心对稀疏的支持

**深度神经网络的稀疏性**

随着深度神经网络发展，计算量与参数量增长，剪枝技术成为有效的推理加速方法，但简单权重裁剪带来的运算吞吐量提升有限，且会导致权重参数值分布随机，现有一些硬件支持稀疏权重卷积的加速器缺乏通用性，不适合 GPGPU 平台，因此稀疏化方法需考虑硬件平台特性。

**Ampere 架构的结构化稀疏支持**

NVIDIA 的 A100 GPGPU 首次在张量核心单元加入稀疏性考虑，支持权重矩阵中 2:4 的结构化稀疏，更适合 GPGPU 架构。利用 A100 稀疏加速的过程包括训练密集权重矩阵、规则剪枝、重训练、压缩存储，张量核心增加硬件支持，通过多路选择器选取非零权重特征图数值相乘，在相同算力下将矩阵乘加计算吞吐量翻倍。

**张量核心的稀疏化改进设计**

在 Ampere 架构推出前，学术界对张量核心的稀疏化支持进行了研究，如提出基于 Volta 架构张量核心实现结构化稀疏矩阵乘加的方法，包括求解权重的结构化稀疏和改进张量核心结构。该方法对权重矩阵进行 Vector Sparse Pruning 剪枝，设定向量长度和非零值数，压缩编码得到矩阵，改进张量核心结构，增加指令和寄存器，调整矩阵元素与线程映射关系，完成稀疏矩阵乘加计算，但实际性能提升低于理论预期，Ampere 架构采用 50% 的稀疏度，解决了数据存取问题，获得更高计算吞吐量提升。

#### 神经网络计算的软件支持

张量核心可加速矩阵乘加计算，但面对深度神经网络庞大算力需求，需上层软件和库函数协同硬件单元加速整个神经网络计算。当前神经网络编程依托框架完成，如 TensorFlow、PyTorch 等，**框架将数据抽象为张量，计算操作抽象为算子，神经网络计算抽象为计算流图，用户定义张量、调用算子组装网络**。

框架前端提供算子和 API，与硬件无关，后端结合神经网络编译工具根据硬件特点生成指令或驱动，面向 GPGPU 开发神经网络，后端会调用 cuDNN 库，该库是针对 NVIDIA GPGPU 支持神经网络低阶原语的加速库，**作为桥梁连接深度学习框架前端与底层 GPGPU 硬件内核函数，用户只需保证框架接入 cuDNN，便可享受 GPGPU 加速**。

#### 深度学习评价基准 ——MLPerf

随着硬件平台计算和存储能力增强，机器学习应用广泛，深度神经网络计算需求推动硬件架构和软件生态发展，为评价支持深度神经网络计算的架构和软件，需要通用评价基准，MLPerf 基准测试套件应运而生，旨在构建公平有意义的基准测试，衡量机器学习硬件、软件和服务的训练和推理性能，得到业界认同。
